# Quick Start

**You can get a result from TaxEase in under two minutes, without an account.** Here is the fastest path through each of the three main areas.

## Run a calculator

1. Open [taxease.aoneahsan.com](https://taxease.aoneahsan.com) and go to **Tools**.
2. Pick a calculator — for example, the **Tax Refund** or **Mortgage** calculator.
3. Fill in the input fields. Sensible defaults are pre-filled so you can see how it works.
4. Press **Calculate**. Results appear instantly next to the form.
5. Use **Print** or **Download PDF** to save a copy, or **Export to Google Drive** if signed in.

Every calculator runs entirely in your browser, so your numbers are not sent anywhere to be computed.

## Generate a document

1. Go to **Tools → Document Generators**.
2. Choose a document — for example, an **NDA**, **Lease Agreement**, or **Employment Contract**.
3. Fill in the parties, dates, and terms.
4. Press **Generate**. A formatted, print-ready document renders on the right.
5. Use **Print / Download PDF** to export it, then have it reviewed by a qualified attorney before use.

## Submit a service request

1. [Sign in](/getting-started/accounts) (this area needs an account).
2. Go to **Services** and pick the service you need.
3. Complete the multi-step request form and attach any required documents.
4. Submit, then watch the request status update from your [dashboard](/features/dashboard).
