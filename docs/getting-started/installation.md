# Installing TaxEase

**TaxEase needs no installation to use on the web** — open [taxease.aoneahsan.com](https://taxease.aoneahsan.com) in any modern browser and start immediately. For a native experience and offline access, install the mobile app.

## Web (no install)

Visit **[taxease.aoneahsan.com](https://taxease.aoneahsan.com)**. The web app works on desktop and mobile browsers. You can use all calculators and document generators without signing in; sign in only to save your work and sync it across devices.

## Android

Install from Google Play:

- **[TaxEase on Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.taxease)** (package `com.aoneahsan.taxease`)

The Android app is built with Capacitor and wraps the same app you get on the web, plus native features: push notifications, the OS share sheet, home-screen shortcuts, deep links, a privacy screen that hides content in the app switcher, and edge-to-edge display.

## iOS

TaxEase is available on the web and Android. **iOS is not currently offered.**

## Browser extension

A companion browser extension lets you capture receipts and expenses from online purchases for tax tracking. See [Browser Extension](/features/browser-extension) for what it does and how it connects to your account.

## System requirements

| Platform | Requirement |
|---|---|
| Web | Any current Chrome, Edge, Firefox, or Safari |
| Android | Android 8.0 (API 26) or newer |
