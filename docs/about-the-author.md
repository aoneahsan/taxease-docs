## About TaxEase

TaxEase is built with React 19, TypeScript, TanStack Router, Radix UI, Firebase, and Capacitor, with a companion WXT browser extension. The documentation you are reading is built with Docusaurus and dual-hosted on Firebase Hosting and GitHub Pages.

If you find an issue in these docs, open an issue or pull request on the [taxease-docs repository](https://github.com/aoneahsan/taxease-docs).
